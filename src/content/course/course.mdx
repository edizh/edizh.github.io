## Description

Already know the basics of Python but want to apply them to real scientific and engineering problems?

[Python for Research and Scientific Computing](https://www.udemy.com/course/python-for-stem/?referralCode=C064F73CE6444DA07905) is a hands-on, project-based course that takes you beyond Python syntax into scientific simulations, numerical modeling, data analysis, and visualization.

You'll learn how to use powerful scientific Python libraries, including NumPy, SciPy, Pandas, Matplotlib, and SymPy, to tackle practical challenges in research and engineering.

What you'll learn through practical projects:

- **Scientific simulations:** Implement Monte Carlo methods, solve coupled differential equations, and simulate physical systems such as harmonic oscillators, satellite orbits, and Brownian motion.
- **Data analysis and particle tracking:** Analyze large datasets with Pandas, extract particle trajectories from video, and investigate statistical properties of experimental and simulated data.
- **Parameter estimation and optimization:** Fit experimental spectra, estimate model parameters, and improve fitting results using numerical optimization techniques.
- **Symbolic modeling and experimental design:** Build physical models with SymPy and optimize measurement strategies using statistical principles.
- **Scientific visualization:** Create clear, high-quality figures with Matplotlib, customize colors and plotting styles, and refine graphics using Inkscape.

**A practical approach to scientific programming**

Rather than focusing on Python syntax alone, this course teaches scientific problem-solving through realistic examples and coding projects. You'll learn not only how to implement numerical methods, but also how to interpret their results and apply the underlying concepts to other scientific problems.

Independent exercises allow you to test your understanding and develop your problem-solving skills. Solutions are provided to support your learning.
